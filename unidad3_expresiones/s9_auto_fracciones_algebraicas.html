45.1. Repaso rápido#

Clase

Tema

Lo más importante

S9·C1

División de monomios

\(\frac{x^m}{x^n}=x^{m-n}\). Casos \(m>n\), \(m=n\), \(m<n\)

S9·C2

Polinomio ÷ monomio

Dividir cada término entre el monomio

Fracciones algebraicas

45.2. Parte 1 — División de monomios#

45.2.1. Ejercicio 1#

Simplifica.

a) \(\frac{x^9}{x^4}\)

b) \(\frac{a^3}{a^3}\)

c) \(\frac{x^2}{x^7}\)

d) \(\frac{-20x^5y^3}{4x^2y^6}\)

Ver solución

a) \(x^{9-4} = x^5\)

b) \(a^{3-3} = a^0 = 1\) (\(a \neq 0\))

c) \(x^{2-7} = x^{-5} = \frac{1}{x^5}\)

d) \(-5x^{5-2}y^{3-6} = -5x^3y^{-3} = \frac{-5x^3}{y^3}\)

45.3. Parte 2 — Polinomio entre monomio#

45.3.1. Ejercicio 2#

Divide.

a) \(\frac{10x^3 - 15x^2 + 5x}{5x}\)

b) \(\frac{12a^4b^2 - 8a^3b^3 + 4a^2b}{4a^2b}\)

c) \(\frac{6x^2 + 9x + 3}{3x}\)

d) \(\frac{-8x^3 + 12x^2 - 4x}{-4x}\)

Ver solución

a) \(2x^2 - 3x + 1\)

b) \(3a^2b - 2ab^2 + 1\)

c) \(2x + 3 + \frac{1}{x}\)

d) \(2x^2 - 3x + 1\)

45.4. Parte 3 — División larga de polinomios#

45.4.1. Ejercicio 3#

Divide y verifica con \(D = d \cdot Q + R\).

a) \(\frac{x^2 + 7x + 12}{x + 3}\)

b) \(\frac{x^2 - 5x + 6}{x - 2}\)

c) \(\frac{2x^3 - 7x^2 + 7x - 2}{x - 2}\)

d) \(\frac{x^3 - 1}{x - 1}\)

Ver solución

a) \(Q = x+4\), \(R = 0\). Verificación: \((x+3)(x+4) = x^2+7x+12\) ✓

b) \(Q = x-3\), \(R = 0\). Verificación: \((x-2)(x-3) = x^2-5x+6\) ✓

c) \(Q = 2x^2-3x+1\), \(R = 0\)

d) \(Q = x^2+x+1\), \(R = 0\)

45.5. Parte 4 — Simplificación de fracciones algebraicas#

45.5.1. Ejercicio 4#

Simplifica e indica restricciones.

a) \(\frac{x^2 - 16}{x^2 - 4x}\)

b) \(\frac{x^2 + 5x + 6}{x^2 - 9}\)

c) \(\frac{2x^2 - 8}{x^2 + 4x + 4}\)

d) \(\frac{x^3 - x}{x^2 - 1}\)

Ver solución

a) \(\frac{(x+4)(x-4)}{x(x-4)} = \frac{x+4}{x}\) (\(x \neq 0, 4\))

b) \(\frac{(x+2)(x+3)}{(x+3)(x-3)} = \frac{x+2}{x-3}\) (\(x \neq -3, 3\))

c) \(\frac{2(x+2)(x-2)}{(x+2)^2} = \frac{2(x-2)}{x+2}\) (\(x \neq -2\))

d) \(\frac{x(x+1)(x-1)}{(x+1)(x-1)} = x\) (\(x \neq -1, 1\))

45.6. Parte 5 — Multiplicación y división#

45.6.1. Ejercicio 5#

Opera y simplifica.

a) \(\frac{x^2 - 1}{x} \cdot \frac{2x}{x + 1}\)

b) \(\frac{x^2 - 4}{3x} \div \frac{x - 2}{9}\)

c) \(\frac{2x^2 - 8}{x^2 - 4x + 4} \cdot \frac{x - 2}{4}\)

d) \(\frac{x^2 + 3x + 2}{x^2 - 1} \div \frac{x + 2}{x - 1}\)

Ver solución

a) \(\frac{(x+1)(x-1)}{x} \cdot \frac{2x}{x+1} = 2(x-1)\)

b) \(\frac{(x+2)(x-2)}{3x} \cdot \frac{9}{x-2} = \frac{3(x+2)}{x}\)

c) \(\frac{2(x+2)(x-2)}{(x-2)^2} \cdot \frac{x-2}{4} = \frac{2(x+2)}{4} = \frac{x+2}{2}\)

d) \(\frac{(x+1)(x+2)}{(x+1)(x-1)} \cdot \frac{x-1}{x+2} = 1\) (\(x \neq -2, -1, 1\))

45.7. Parte 6 — Identificar el método#

45.7.1. Ejercicio 6#

Indica qué técnica usar y resuelve.

a) \(\frac{15x^4y^2}{3x^2y^5}\)

b) \(\frac{8x^3 - 12x^2 + 4x}{4x}\)

c) \(\frac{x^3 + 6x^2 + 11x + 6}{x + 1}\)

d) \(\frac{x^2 - 6x + 9}{x^2 - 9}\)

Ver solución

a) División de monomios: \(5x^2y^{-3} = \frac{5x^2}{y^3}\)

b) Polinomio ÷ monomio: \(2x^2 - 3x + 1\)

c) División larga: \(Q = x^2+5x+6\), \(R = 0\)

d) Simplificar (factorizar): \(\frac{(x-3)^2}{(x+3)(x-3)} = \frac{x-3}{x+3}\) (\(x \neq -3, 3\))

45.8. Parte 7 — Problema integrador de ingeniería#

45.8.1. Ejercicio 7#

Un sistema de transmisión tiene relación:

\[i = \frac{\omega_1}{\omega_2} = \frac{3x^2 + 6x}{x^2 - 4} \cdot \frac{x - 2}{x + 1}\]

a) Factoriza y simplifica la expresión de \(i\).

b) El rendimiento es \(\eta = \frac{P_2}{P_1}\) donde \(P_1 = 2x^2 + 4x\) y \(P_2 = x^2 - 4\). Simplifica \(\eta\).

c) La fuerza de salida es \(F_s = \frac{F_e \cdot d_e}{d_s}\). Si \(F_e = 6x^2 + 9x + 3\) y \(d_s = 3x\), halla \(F_s\) simplificada.

d) Divide \(\frac{x^3 - 7x + 6}{x - 2}\) y verifica.

Ver solución

a) \(\frac{3x(x+2)}{(x+2)(x-2)} \cdot \frac{x-2}{x+1} = \frac{3x}{x+1}\) (\(x \neq -2, 2, -1\))

b) \(\eta = \frac{x^2-4}{2x^2+4x} = \frac{(x+2)(x-2)}{2x(x+2)} = \frac{x-2}{2x}\) (\(x \neq -2, 0\))

c) \(F_s = \frac{6x^2+9x+3}{3x} = 2x + 3 + \frac{1}{x}\)

d) \(Q = x^2+2x-3\), \(R = 0\). Verificación: \((x-2)(x^2+2x-3) = x^3-7x+6\) ✓

45.11. Resumen de la semana#

Clase

Lo que debes dominar

S9·C1

\(\frac{x^m}{x^n}=x^{m-n}\). Tres casos según \(m\) y \(n\).

S9·C2

Dividir cada término del polinomio entre el monomio. \(\sigma=F/A\).

S9·C3

Algoritmo de división larga. \(D=d\cdot Q+R\). Verificar siempre.

S9·C4

Simplificar factorizando. Multiplicar y dividir (recíproco). Transmisión y \(\eta\).
