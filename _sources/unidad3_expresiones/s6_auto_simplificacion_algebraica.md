## Parte 1 — Propiedades de la igualdad

### Ejercicio 1

Indica qué propiedad se usa en cada paso para resolver la ecuación:

$$3x + 8 = 23$$
$$3x = 15 \quad \text{(a)}$$
$$x = 5 \quad \text{(b)}$$

::::{admonition} Ver solución
:class: dropdown
**(a)** Propiedad de **sustracción** (se restaron 8 en ambos lados)

**(b)** Propiedad de **división** (se dividió entre 3 en ambos lados)
::::

---

### Ejercicio 2

Resuelve y justifica cada paso con la propiedad usada.

**a)** $x - 9 = 14$

**b)** $\frac{x}{5} = 8$

**c)** $4x - 3 = 17$

::::{admonition} Ver solución
:class: dropdown

**a)** $x - 9 + 9 = 14 + 9$ (adición) → $x = 23$

**b)** $\frac{x}{5} \cdot 5 = 8 \cdot 5$ (multiplicación) → $x = 40$

**c)**
$4x - 3 + 3 = 17 + 3$ (adición) → $4x = 20$
$\frac{4x}{4} = \frac{20}{4}$ (división) → $x = 5$
::::

## Parte 2 — Términos semejantes

### Ejercicio 3

Simplifica combinando términos semejantes.

**a)** $7x^2 - 3x + 5x^2 + 8x - 2$

**b)** $4ab - 2a^2b + 3ab - a^2b + 5$

**c)** $\frac{1}{2}x + \frac{3}{4}x - 2x + 7$

::::{admonition} Ver solución
:class: dropdown

**a)** $(7x^2 + 5x^2) + (-3x + 8x) - 2 = 12x^2 + 5x - 2$

**b)** $(4ab + 3ab) + (-2a^2b - a^2b) + 5 = 7ab - 3a^2b + 5$

**c)** $(\frac{1}{2} + \frac{3}{4} - 2)x + 7 = (\frac{2}{4} + \frac{3}{4} - \frac{8}{4})x + 7 = -\frac{3}{4}x + 7$
::::

## Parte 3 — Suma y resta de polinomios

### Ejercicio 4

**a)** $(5x^2 - 3x + 7) + (2x^2 + 4x - 1)$

**b)** $(5x^2 - 3x + 7) - (2x^2 + 4x - 1)$

**c)** $(3a^2 - 2ab + b^2) + (a^2 + 5ab - 3b^2)$

**d)** $(3a^2 - 2ab + b^2) - (a^2 + 5ab - 3b^2)$

::::{admonition} Ver solución
:class: dropdown

**a)** $7x^2 + x + 6$

**b)** $(5x^2 - 3x + 7) - 2x^2 - 4x + 1 = 3x^2 - 7x + 8$

**c)** $4a^2 + 3ab - 2b^2$

**d)** $(3a^2 - 2ab + b^2) - a^2 - 5ab + 3b^2 = 2a^2 - 7ab + 4b^2$
::::

## Parte 4 — Multiplicación

### Ejercicio 5

**a)** $4x^2(3x^3 - 2x + 5)$

**b)** $(x + 6)(x - 2)$

**c)** $(3x - 4)(2x + 5)$

**d)** $(x + 3)(x^2 - 2x + 4)$

::::{admonition} Ver solución
:class: dropdown

**a)** $12x^5 - 8x^3 + 20x^2$

**b)** $x^2 - 2x + 6x - 12 = x^2 + 4x - 12$

**c)** $6x^2 + 15x - 8x - 20 = 6x^2 + 7x - 20$

**d)**
$= x(x^2 - 2x + 4) + 3(x^2 - 2x + 4)$
$= x^3 - 2x^2 + 4x + 3x^2 - 6x + 12$
$= x^3 + x^2 - 2x + 12$
::::

## Parte 5 — Problema integrador de ingeniería

### Ejercicio 6

Una empresa fabrica tubos de acero cilíndricos. El volumen de material del tubo (sin incluir el interior hueco) se calcula como:

$$V = \pi L (R_{ext}^2 - R_{int}^2)$$

Donde $L$ es la longitud, $R_{ext}$ es el radio exterior y $R_{int}$ es el radio interior.

Si $R_{ext} = r + t$ y $R_{int} = r$ (donde $r$ es el radio interior y $t$ es el espesor de la pared):

**a)** Expande $R_{ext}^2 = (r + t)^2$

**b)** Calcula $R_{ext}^2 - R_{int}^2 = (r+t)^2 - r^2$

**c)** Simplifica la expresión del volumen $V = \pi L [(r+t)^2 - r^2]$

**d)** Si $r = 50$ mm, $t = 5$ mm, $L = 300$ mm, calcula $V$ usando tu expresión simplificada.

::::{admonition} Ver solución
:class: dropdown

**a)** $(r + t)^2 = r^2 + 2rt + t^2$

**b)** $(r+t)^2 - r^2 = r^2 + 2rt + t^2 - r^2 = 2rt + t^2 = t(2r + t)$

**c)** $V = \pi L \cdot t(2r + t)$

**d)** $V = \pi \cdot 300 \cdot 5 \cdot (2 \cdot 50 + 5) = \pi \cdot 300 \cdot 5 \cdot 105$

$V = \pi \cdot 157500 \approx 494{,}801 \text{ mm}^3 \approx 494.8 \text{ cm}^3$
::::

```{raw} html

<script>
(function() {
    function init() {
        if (typeof JXG === 'undefined') { setTimeout(init, 200); return; }
        JXG.Options.text.useMathJax = false;
        var board = JXG.JSXGraph.initBoard('jxg-s6auto-tubo', {
            boundingbox: [-1, 11, 13, -3],
            axis: false, showCopyright: false, showNavigation: false,
            pan: { enabled: false }, zoom: { enabled: false }
        });

        var slR = board.create('slider', [[8, 9],[12, 9],[10, 50, 100]], {
            name: 'r (mm)', snapWidth: 5, fillColor: '#3b82f6' });
        var slT = board.create('slider', [[8, 7.5],[12, 7.5],[1, 5, 20]], {
            name: 't (mm)', snapWidth: 1, fillColor: '#f97316' });
        var slL = board.create('slider', [[8, 6],[12, 6],[50, 300, 500]], {
            name: 'L (mm)', snapWidth: 50, fillColor: '#16a34a' });

        function r(s) { return Math.round(s.Value()); }

        // Dibujar sección transversal del tubo
        var cx = 3.5, cy = 5;

        function dibujarTubo() {
            var ri = r(slR) / 20;  // escala visual
            var re = (r(slR) + r(slT)) / 20;

            board.create('circle', [[cx, cy], re], {
                fillColor: '#94a3b8', fillOpacity: 0.5,
                strokeColor: '#374151', strokeWidth: 2 });
            board.create('circle', [[cx, cy], ri], {
                fillColor: '#f8fafc', fillOpacity: 1,
                strokeColor: '#374151', strokeWidth: 2 });
        }

        // Texto dinámico
        board.create('text', [8, 4.5, function() {
            var ri = r(slR), t = r(slT), L = r(slL);
            var V = Math.PI * L * t * (2*ri + t);
            return 'V = pi * L * t * (2r + t)';
        }], { fontSize: 12, color: '#374151' });

        board.create('text', [8, 3.5, function() {
            var ri = r(slR), t = r(slT), L = r(slL);
            var V = Math.PI * L * t * (2*ri + t);
            return '= pi * ' + L + ' * ' + t + ' * ' + (2*ri+t);
        }], { fontSize: 12, color: '#374151' });

        board.create('text', [8, 2.5, function() {
            var ri = r(slR), t = r(slT), L = r(slL);
            var V = Math.PI * L * t * (2*ri + t);
            return 'V = ' + Math.round(V) + ' mm³';
        }], { fontSize: 15, color: '#1d4ed8', fontWeight: 'bold' });

        board.create('text', [3.5, 9, 'Seccion transversal'], {
            fontSize: 11, color: '#6b7280', anchorX: 'middle' });

        dibujarTubo();
    }
    init();
})();
</script>
```
